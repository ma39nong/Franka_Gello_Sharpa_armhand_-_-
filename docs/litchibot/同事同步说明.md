## 三、GUI 的正确语义

### Start hand / Stop hand

手套进程不是由按钮启动的。full launcher 启动后，以下内容持续运行：

```text
glove input
retarget
Sharpa state
tactile
supervisor
```

GUI 按钮只控制运动授权：

```text
Left Start hand
→ 允许左 Sharpa command forwarding

Right Start hand
→ 允许右 Sharpa command forwarding

Stop hand
→ 撤销对应侧 forwarding permit
```

Start hand 不是 safety bypass。即使点击 Start hand，仍然必须通过：

```text
NaN / Inf
22D joint order
joint limits
freshness
watchdog
timeout
raw/final target integrity
FAULT latch
```

如果 supervisor FAULT，GUI 不能通过重新点击 Start hand 清除故障。

### Manus 与 LitchiBot 的 GUI 状态

两种 source 都通过同一个 authenticated hand supervisor 反馈真实状态：

```text
DISABLED
READY
ACTIVE
PAUSED / WARNING
FAULT / HARD_FAULT
```

GUI 不再仅根据自己是否点击过按钮来假设手部 ACTIVE。

### DISENGAGE ALL

`DISENGAGE ALL` 保留原 arm backend 的行为，并增加双手 permit 撤销：

```text
Left arm OFF
Right arm OFF
Left hand OFF
Right hand OFF
```

它不会杀死 Manus、LitchiBot、retarget、Sharpa state 或 tactile 进程。

## 四、Home 的正确语义

根据最新确认，Sharpa 手启动后会持续跟随手套，不要求长期保持一个固定 Home 姿态。因此 GUI 保持 Wuji-Franka 风格：

```text
Home both arms
```

它主要负责原有 FR3 arm Home，并撤销 arm followers。不会要求创建 Sharpa 22D 固定 Home，也不会向 Sharpa 猜测发送固定开手姿态。

手部恢复跟随的方式是：

```text
手套 source 持续运行
→ 点击对应侧 Start hand
→ supervisor 通过安全检查
→ Sharpa 开始跟随实时 hand target
```

旧 Wuji hand 的 Home/capture 逻辑仍属于原 arm backend；不要把 Wuji 20D Home 文件当作 Sharpa 22D Home 使用。

## 五、原 GUI 问题的原因

过去 GUI 中的 hand 按钮发往：

```text
Operator GUI
→ arm backend OperatorControlServer
→ OperatorConsole.hand_active
```

但生产 Terminal 2 的 Manus + Sharpa 是独立进程，未订阅这个旧内存状态，所以以前会出现：

```text
GUI 看起来有 Start hand
但 Terminal 2 的 Sharpa hand 没有收到对应 permit
```

现在 full 模式使用：

```text
Operator GUI
→ HandClient JSON/TCP
→ HandControlServer
→ shared MotionLatch / normal hand authority
→ Sharpa command forwarding
```

arm controls 仍然走原 arm backend，不与 hand permit 混在一起。

## 八、停止流程

正常停止：

1. 点击 `DISENGAGE ALL`。
2. 在 full launcher 终端按 `Ctrl+C`。
3. 等待 launcher 清理 hand、GUI、arm Docker 子进程。
4. 不要手动启动第二个 wrapper 来“补救”。

原独立调试入口继续保留，但不要和 full launcher 同时运行：

```bash
./ops/run/run_gello_arms_only.sh
./ops/run/run_sharpa_hands_cyclonedds.sh
```
